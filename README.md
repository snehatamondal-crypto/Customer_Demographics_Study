# Customer_Demographics_Study
Excel-based Customer Demographics Analysis Dashboard using Pivot Tables,Charts, and Interactive Slicers.

📌 Project Overview

The Customer Demographics Study is an Excel-based data analysis and visualization project. The main objective of this project is to analyze customer information and understand customer demographics based on age, gender, occupation, marital status, education, and region.

This interactive dashboard provides meaningful insights into customer distribution and demographic patterns through charts, KPI cards, and interactive slicers.

🎯 Project Objectives

- Analyze total customer data.
- Understand customer age distribution.
- Compare male and female customers.
- Analyze customers based on occupation.
- Study marital status distribution.
- Identify customer distribution by region.
- Analyze customers based on education level.

🛠️ Tools & Technologies

- Microsoft Excel
- Data Cleaning
- Data Analysis
- Charts & Visualizations
- Pivot Tables
- Interactive Slicers
- Dashboard Design

📈 Key Dashboard Insights

The dashboard highlights the following information:

- Total Customers: 1,500
- Average Age: 38.36
- Male Customers: 725
- Female Customers: 753

Dashboard Visualizations

1. Age Group Distribution
2. Customer by Occupation
3. Customer by Marital Status
4. Customer by Region
5. Gender Distribution
6. Customer by Education

🎛️ Interactive Features

The dashboard includes interactive slicers to filter customer data by:

- Age
- State/Region
- Education
- Marital Status
- Gender

These filters help users explore customer demographics from different perspectives.
